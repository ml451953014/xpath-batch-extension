# XPath 批量文字提取

一个完全在浏览器本地运行的 Chrome / Edge 扩展：在网页列表中点选两个同类字段，自动推导 XPath，批量预览并导出文字、链接或其他属性。

## 它解决什么问题

从网页列表整理数据，通常只有三种笨办法：逐条复制、临时写脚本，或把页面内容交给在线采集服务。

这个扩展把流程缩短成：

1. 点击两条记录中的同一字段；
2. 核对自动推导的 XPath 和完整预览；
3. 复制结果或导出 CSV。

它的核心价值是：**不写代码，也能快速把重复网页内容变成结构化表格；数据不上传，登录后页面也可以在本地处理。**

## 为什么值得用

- **上手快**：两个样本即可推导批量规则，不必先学习 XPath
- **按记录对齐**：标题、作者、链接等多列按同一条记录配对；缺值保留空格，不会串行
- **完全本地**：无服务端、无大模型、无遥测，页面内容不会发送到外部
- **结果可核对**：先显示命中数量、页面高亮和完整预览，再允许导出
- **支持高级用法**：可直接编辑 XPath，提取 `href`、`src`、`id`、`class` 和文本节点
- **零构建安装**：不需要 Node.js 或打包工具，下载源码即可加载

## 典型场景

- 整理搜索结果、商品列表、论坛帖子或后台表格
- 批量收集标题、作者、价格、查看数、链接等字段
- 快速验证 XPath 是否覆盖了正确的页面元素
- 在不上传页面内容的前提下处理登录后的内部页面

## 安装

1. 下载本仓库：点击 GitHub 页面右上方 **Code → Download ZIP**，并解压缩。
2. 在 Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的项目根目录。
5. 把“XPath 批量文字提取”固定到浏览器工具栏。

## 快速使用

1. 打开包含重复列表的普通网页，点击扩展图标。
2. 点击“开始拾取”，依次点击两条记录中的同一字段。
3. 检查候选 XPath、命中数量、高亮和预览。
4. 直接复制文本，或添加更多字段后导出 CSV。

多字段模式会按共同记录行对齐数据。某条记录缺少字段时保留空单元格；一个字段命中多个节点时会提示歧义，而不是静默取错值。

## 隐私与权限

扩展只申请：

- `activeTab`：仅在你主动点击扩展时访问当前标签页
- `scripting`：把本地提取逻辑注入当前页面

它不申请全站访问、Cookie、历史记录或持久化存储权限，也不包含外部 API、远程脚本和遥测。

## 能力边界

- 只处理当前页面主文档中已经加载到 DOM 的内容
- 不自动翻页、点击“加载更多”或滚动抓取
- 不穿透 iframe、Shadow DOM、canvas 和浏览器内置 PDF 预览
- 动态或虚拟列表变化后，需要刷新数据并重新核对
- 两个样本只能推导结构规律，无法理解业务语义；导出前应检查完整预览

更完整的操作、XPath 示例、安全设计和测试说明见 [中文详细文档](./README.zh-CN.md)。

## 项目结构

```text
manifest.json   扩展清单与最小权限声明
background.js   工具栏点击与脚本注入
core.js         XPath 推导、文本与 CSV 工具
content.js      单字段拾取、预览和高亮
table-core.js   记录识别、多字段对齐和导出
table-ui.js     多字段配置与表格界面
```
